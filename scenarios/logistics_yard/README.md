# Scenario: logistics yard

The site the demo scores. Frozen at the hour-10 sync (decision 008).

- `site.json`: a 190 m × 110 m fenced yard with four entry points, a high-value cage at the rear of the warehouse footprint (the asset), two drone docks in opposite corners, a ground-robot dock by the guard house, two fixed cameras and three benign traffic routes; response time 20 s and intruder speed cap 2.0 m/s (decision 008 amendments).
- `fleets/`: the twelve configurations of the sweep, generated by `scripts/make_fleet_configs.py`; `sweep.json` names them and the baseline.
- `sensor_curve.json`: the stub curve with a 360-degree drone disc, until lane A's calibrated curve replaces it.
- `redteam_config.json`: adversary scenario parameters (speed band, waypoint limit, tolerances, search and LLM budgets).
- `costs.md`: the cost-per-hour table and its derivation.

Run anything against it with the scene flags:

```bash
uv run airtight-redteam difficulty --site scenarios/logistics_yard/site.json --fleet scenarios/logistics_yard/fleets/d2_go2_guard_sync.json --curves scenarios/logistics_yard/sensor_curve.json --config scenarios/logistics_yard/redteam_config.json --engine v0 --workers 8
```

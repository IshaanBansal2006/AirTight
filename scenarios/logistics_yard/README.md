# Scenario: logistics yard

The site the demo scores. Frozen at the hour-10 sync (decision 008).

- `site.json`: a 190 m × 110 m fenced yard with four entry points, a high-value cage at the rear of the warehouse footprint (the asset), two drone docks in opposite corners, a ground-robot dock by the guard house, two fixed cameras and three benign traffic routes.
- `fleets/`: the twelve configurations of the sweep, generated by `scripts/make_fleet_configs.py`; `sweep.json` names them and the baseline.
- `redteam_config.json`: adversary scenario parameters (speed band, waypoint limit, tolerances, search and LLM budgets).
- `costs.md`: the cost-per-hour table and its derivation.

Run anything against it with the scene flags:

```bash
uv run airtight-redteam difficulty --site scenarios/logistics_yard/site.json --fleet scenarios/logistics_yard/fleets/d2_go2_guard_sync.json --config scenarios/logistics_yard/redteam_config.json --workers 8
```
